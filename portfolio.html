Action-Conditioned Video Generation World Model 상세 보기 →
2026.07 ~ 2026.08 (챌린지 마감 2026-08-20)
2026 INHA AI Challenge (Dacon 236736) · Independent Entry
[프로젝트 소개]
  • 첫 프레임과 joint-action 시퀀스가 주어졌을 때 로봇의 미래 프레임을 예측하는 action-conditioned video generation world model. 채점식 0.3·(1−DINO) + 0.3·(1−R3D) + 0.4·act_mae (lower better).
[기존 문제점]
  • Cosmos-Predict3-Nano 프리트레인 action distribution과 태스크의 절대 joint-angle 표현 사이의 방향성 mismatch.
  • LoRA 소자 튜닝만으로는 리더보드 유의한 개선 어려움.
[해결 방안]
  • Action Injection Module (action_proj_in/out + action-modality embedding) 직접 학습.
  • LoRA rank 32 — attention (add_q/k/v_proj, to_add_out) + MLP (gate/up/down_proj) 파인튜닝.
  • 액션 표현을 End-Effector delta + gripper [0,1] 정규화로 재설계.
  • ANCHORED_soft 앙상블로 안전본(v5_base) 방어 + B4 sweep step 6000 도전본으로 개선.
[성과]
  • Action Injection MAE −43.2%, LoRA −8.6%, EE-Delta −8.5%. Action MAE ↔ LB 상관 r = +0.820 검증.
  • 최종 도전본 LB 0.2407 (B4 sweep step 6000) / 안전본 LB 0.24524 (v5_base ANCHORED_soft) — 안전본 대비 −0.0045 개선.
  • 6일 스프린트 6개 도전 트랙(Track A~E + Robot-Factored WM) 모두 안전본 후퇴로 회귀 판정 후 단일 축 최적화 pivot. Blackwell(sm_120) 실측으로 nightly torch env 신설, diffusion step 7배 가속.
