실기 SO-101 양팔 로봇에서 시연을 수집하고, 해당 데이터를 이용해 VLA 정책을 학습한 뒤 실제 로봇에서 폐루프 실행을 평가하는 전체 연구 흐름입니다.

다음 연구 질문으로 이어진 경험

SO-101 실기 로봇의 teleoperation 시연을 직접 수집하고 VLA 정책을 학습·평가하면서, 실제 환경에서 다양한 상태와 행동을 충분히 경험시키는 데이터의 중요성을 체감했습니다. 시연 수집은 시간과 장비가 필요한 과정이므로, 이후에는 World Model로 학습 데이터를 생성·확장할 수 있을까?라는 질문으로 관심을 넓혔습니다.

이후 별도 SO-100 데이터셋을 사용한 World Model 프로젝트에서 action-conditioned rollout을 생성하고, train/eval action 분포와 생성 결과의 Good/Bad case를 분석하며 action 표현과 모델 튜닝을 진행했습니다. 두 프로젝트의 데이터셋을 직접 이어 붙인 것은 아니며, 실제 로봇 학습 경험에서 얻은 데이터 효율성에 대한 문제의식이 후속 연구 질문에 영향을 준 흐름입니다.

요약. 팀 리더로서 SO-101 양팔 로봇의 teleoperation 시연 수집, LeRobot 기반 ACT·SmolVLA 비교, Point Cloud/FPS와 다중 카메라·로봇 상태 입력 구성, SmolVLA action expert LoRA 적응 실험, 실기 rollout까지 연결했습니다. 입력 구성의 구현 사실과 성능 기여도에 대한 검증은 구분해 기록합니다.

01 · Problem Definition — Real-Robot Imitation Learning

양팔 조작 정책은 물체와 두 로봇 팔의 상대적 위치, 카메라 시점, 로봇의 관절 상태를 함께 고려해야 합니다. RGB 영상만으로도 장면을 인식할 수 있지만, 깊이와 3차원 위치 정보가 필요한 조작에서는 이미지 좌표만으로 공간 관계를 추정해야 하는 부담이 있습니다. 이 프로젝트에서는 실제 로봇 시연을 수집하고, RGB·Point Cloud·로봇 상태 정보를 정책 입력으로 구성하는 방법을 탐색했습니다.

02 · System Setup & Demonstration Data

SO-101 양팔 로봇과 리더-팔로워 teleoperation 환경을 구성하고, 작업자가 리더 로봇을 조작하는 동안 팔로워 로봇의 동작과 카메라 관측, 로봇 상태, 액션을 에피소드 단위로 기록했습니다. 수집한 시연은 Hugging Face LeRobot 데이터 형식으로 정리해 정책 학습과 실제 로봇 평가에 사용했습니다.

관측 장치는 Top·Front·Wrist 시점의 RGB 카메라와 RealSense 깊이 카메라로 구성했습니다. Top·Front 시점은 작업 공간과 물체의 배치를 넓게 관찰하고, Wrist 시점은 말단부 주변의 조작 상황을 가까이서 관찰합니다. 깊이 영상에서는 Point Cloud를 복원할 수 있으며, 로봇 관절 상태(proprioception)와 액션 정보도 시각 관측의 시점에 맞춰 정렬해 기록했습니다.

정책 학습에 사용한 관측·액션 데이터의 전체 구조입니다. Top·Front·Wrist RGB 영상과 Point Cloud/FPS, 로봇 상태 정보를 시점에 맞춰 구성하고, 정책이 양팔 로봇의 액션을 예측하는 흐름을 나타냅니다. 세부 입력 조합은 정책별 실험 단계에 따라 확장했습니다.

03 · Method — Policy Learning & Multi-modal Observation

ACT를 이용한 초기 모방학습

초기 정책은 LeRobot에서 지원하는 ACT(Action Chunking with Transformers)로 구성했습니다. ACT는 관측으로부터 일정 구간의 액션 시퀀스를 청크 단위로 예측하는 모방학습 정책입니다. 시연 에피소드에 기록된 관측과 액션의 시간적 대응 관계를 학습하고, 학습한 정책을 SO-101 양팔 로봇에서 실행하는 초기 기준선으로 사용했습니다.

카메라 관측 확장과 SmolVLA 적용

ACT 기반 실기 모방학습 경로를 구성한 뒤, 관측 범위를 넓힌 조건에서 사전학습 VLA 정책을 활용할 수 있는지 확인하기 위해 카메라 구성을 확장하고 SmolVLA를 적용했습니다. SmolVLA는 사전학습된 vision-language-action 정책이라는 점에서, 제한된 로봇 시연을 활용해 정책을 적응시키는 별도의 실험 경로를 탐색할 수 있었습니다.

SmolVLA 실험에서는 전체 모델을 모두 업데이트하는 대신 action expert에 LoRA를 적용했습니다. 이는 제한된 시연 데이터로 정책을 적응시키는 과정에서 학습 가능한 파라미터를 줄이는 접근입니다. 공개 OXE 데이터와 SO-101에서 수집한 시연을 활용한 학습·적응 흐름을 실험했으며, ACT와 SmolVLA의 결과를 동일 조건의 정량 비교로 해석하지 않았습니다.

RGB·Point Cloud·FPS의 역할

RGB 영상은 물체의 외관과 장면 맥락을 제공하고, Point Cloud는 깊이 영상에서 복원한 3차원 좌표를 통해 공간 구조를 표현합니다. 점군은 원본 상태에서 밀집되거나 특정 영역에 편중될 수 있어 Farthest Point Sampling(FPS)을 적용해 공간적으로 분포된 점을 선택했습니다. 이는 3차원 기하 정보를 관측에 포함하기 위한 입력 구성으로, 성능 향상을 입증한 결과와는 구분합니다.

다중 카메라와 로봇 상태의 시간 정렬

Top·Front·Wrist 카메라는 서로 다른 시점과 관측 범위를 제공합니다. 한 시점에서 가려진 물체나 말단부 주변의 상황을 다른 시점으로 보완하도록 구성했습니다. proprioceptive state는 관절 위치 등 로봇 자체의 상태를 나타내며, 시각 관측과 함께 사용하면 정책이 장면뿐 아니라 로봇의 현재 상태도 참조할 수 있습니다. 카메라별 입력과 로봇 상태는 액션 시점에 맞춰 정렬하는 것이 중요합니다.

리더-팔로워 방식의 실기 시연 수집 장면입니다. 작업자의 리더 로봇 조작에 따라 팔로워 로봇이 동작하며, 이때의 관측과 액션을 학습용 에피소드로 기록합니다.

학습한 정책을 실제 SO-101 양팔 로봇에서 실행한 폐루프 롤아웃 예시입니다. 컵을 집고 이동하는 동작을 통해 정책의 액션 출력이 실제 로봇 제어로 이어지는 과정을 확인했습니다.

RealSense 깊이 영상에서 복원한 Point Cloud와 FPS 샘플링 결과입니다. FPS는 원본 점군의 밀집도를 줄이고 공간 전반에 분포한 점을 선택해 3차원 기하 정보를 일정한 크기의 입력으로 구성하는 데 사용했습니다.

개인 기여 범위

팀 리더로서 SO-101 리더-팔로워 teleoperation과 시연 수집, LeRobot 데이터·학습 파이프라인, ACT 기반 정책 학습 및 실제 로봇 롤아웃을 연결했습니다. 이후 카메라 관측 구성을 확장하고 SmolVLA를 적용해 action expert LoRA 기반 적응 실험을 진행했으며, Point Cloud/FPS와 proprioceptive state를 포함한 관측 구성도 다뤘습니다.

04 · Experiments & Results

실험은 ACT를 이용한 초기 실기 모방학습에서 출발해, 카메라 관측을 확장한 SmolVLA 적용으로 이어졌습니다. 각 단계는 정책 구조와 관측 구성이 달라 동일한 조건의 모델 성능 비교라기보다, 실제 로봇 시연을 정책 학습과 실행으로 연결하고 후속 VLA 적응을 시도한 순차적 실험으로 해석해야 합니다.

Experiment 1 · ACT 기반 실기 모방학습

  • 데이터: SO-101 양팔 로봇의 리더-팔로워 teleoperation으로 수집한 제한된 시연 에피소드
  • 학습: LeRobot 파이프라인에서 관측과 액션 시퀀스를 사용해 ACT 정책 학습
  • 실행 시나리오: 학습 정책을 실제 양팔 로봇에 배포하고 컵을 집어 이동하는 조작 동작을 폐루프 방식으로 실행
  • 확인 결과: 시연 데이터 수집부터 정책 학습, 실제 로봇 액션 실행까지 이어지는 모방학습 경로를 확인

Experiment 2 · 다중 카메라 확장과 SmolVLA 적응

  • 변경점: ACT 기반 초기 실험 이후 카메라 관측 구성을 확장하고 SmolVLA 정책을 적용
  • 데이터·학습: 공개 OXE 데이터와 제한된 SO-101 시연을 활용한 학습·적응을 시도하고, action expert에 LoRA 적용
  • 확인 결과: 사전학습 VLA 정책을 로봇 시연에 적응시키는 실험 경로와 파라미터 효율적 미세조정 방식을 확인

결과 해석

현재 확인 가능한 성과는 ACT 정책의 실제 양팔 로봇 폐루프 실행과, 관측 구성을 확장한 SmolVLA·LoRA 적응 실험을 수행했다는 점입니다. 다만 ACT와 SmolVLA는 데이터 구성과 카메라 입력, 정책 구조가 동일하게 통제된 비교 실험이 아니며, 정책별 성공률·반복 횟수·궤적 오차를 비교한 정량 벤치마크도 확보하지 않았습니다.

05 · Technical Issues & Improvements

ACT — 시연 기반 단일 태스크 모방학습

ACT는 수집한 시연으로부터 다음 한 시점의 동작만 예측하는 대신 여러 시점의 액션을 하나의 chunk로 예측합니다. 원 논문은 action chunking으로 유효한 예측 horizon을 줄이고, 겹치는 chunk의 temporal ensembling으로 동작을 부드럽게 연결해 모방학습에서 발생하는 오차 누적을 완화하는 접근을 제시합니다. 태스크별 시연으로 정책을 학습하는 구조이므로, 정해진 조작 과제를 빠르게 학습하고 실제 로봇에 연결하는 기준선으로 활용하기 좋습니다. 반면 정책이 학습한 시연 분포에 크게 의존하기 때문에 물체 위치·초기 상태·조작 방식이 달라지면 학습 데이터 밖의 상태로 벗어나 성능이 저하될 수 있습니다. ACT 원 논문

SmolVLA — 사전학습 표현을 활용하는 Vision-Language-Action 정책

SmolVLA는 여러 카메라 영상, 로봇의 sensorimotor state, 자연어 지시를 함께 입력받고 action expert가 연속적인 액션 chunk를 생성하는 VLA 구조입니다. ACT가 특정 태스크의 시연을 중심으로 정책을 학습하는 접근이라면, SmolVLA는 공개 로봇 데이터로 사전학습한 시각·언어 표현을 태스크별 시연으로 적응시키는 방향입니다. 따라서 다양한 태스크와 지시를 공유하는 표현을 활용할 가능성이 있지만, 사전학습만으로 새로운 로봇·카메라·작업 조건에 자동으로 적응하는 것은 아닙니다. Hugging Face의 공식 가이드도 자체 환경에 맞는 fine-tuning과 작업 변형별 시연 데이터 확보를 권장하며, 공개 예시에서는 50개 에피소드로 여러 물체 위치 변형을 수집한 반면 25개 에피소드만 사용한 데이터는 성능이 부족했다고 설명합니다. 이 수치는 보편적인 최소 요구량이 아니라 해당 예시에서 관찰한 데이터 규모·다양성의 중요성을 보여주는 사례입니다. SmolVLA 논문 · SmolVLA 기술 소개 및 벤치마크 · LeRobot fine-tuning 가이드

두 접근의 차이와 본 프로젝트에서의 해석

두 정책은 단순히 모델 크기나 성공률로 우열을 나누기보다, 학습에 활용하는 사전 지식과 적용하려는 문제 범위가 다릅니다. ACT는 태스크별 시연을 직접 학습해 동작을 예측하는 구조로, 데이터와 태스크가 명확한 조건에서 구현·검증 경로가 비교적 단순합니다. SmolVLA는 사전학습된 VLA 표현과 언어 조건을 활용해 태스크 적응과 다중 작업 확장 가능성을 제공하지만, 로봇별 관측 스키마 정합성, 태스크별 시연의 다양성, 미세조정 및 추론 자원까지 함께 고려해야 합니다.

본 프로젝트에서는 ACT를 먼저 학습해 SO-101 양팔 로봇에서 실제 롤아웃을 수행했고, 이후 카메라 관측을 확장한 조건에서 SmolVLA와 action expert LoRA를 적용하는 실험을 진행했습니다. 외부 연구에서 SmolVLA가 ACT를 포함한 기준선보다 높은 성능을 보고한 벤치마크가 있지만, 이는 연구진이 정한 태스크·데이터·평가 환경의 결과입니다. 본 프로젝트의 ACT와 SmolVLA는 학습 데이터와 관측 구성이 동일하게 통제되지 않았으므로 그 결과를 그대로 가져와 자체 실험의 우열로 해석할 수 없습니다. 여기서 확인한 것은 ACT의 실기 모방학습 경로를 구성하고, 사전학습 VLA를 로봇 데이터에 적응시키는 별도 경로를 탐색했다는 점입니다.

구현 과정에서 확인한 제약과 개선 방향

실험을 진행하며 정책 구조뿐 아니라 시연 데이터가 포함하는 물체 위치·초기 상태·조작 변형의 범위, 카메라 입력 이름과 해상도, 로봇 상태 및 액션 표현의 정합성이 학습과 배포를 좌우한다는 점을 확인했습니다. 특히 사전학습 VLA를 사용하더라도 실제 로봇에 적용하려면 태스크별 시연과 관측 스키마를 맞추는 과정이 필요합니다. 이후에는 단순히 시연 수를 늘리는 것보다 실패가 발생한 조건과 미포함된 변형을 구분해 수집하고, 태스크 적응에 필요한 데이터의 효율을 높이는 방향으로 연구를 확장하고자 합니다.

실험에서는 ACT와 SmolVLA의 카메라 구성과 학습 데이터가 동일하지 않아, 두 정책의 결과를 모델 구조만의 차이로 비교하기 어려웠습니다. 또한 카메라 입력 이름·해상도와 로봇 상태 및 액션 표현을 실제 SO-101 환경에 맞추는 과정이 필요했습니다. 다음 실험에서는 관측 구성과 시연 데이터를 먼저 통일하고, 물체 위치·초기 상태·조작 방식이 달라지는 조건을 나누어 수집해 정책별 적응 과정을 비교할 예정입니다.

06 · Follow-up Research Question — Data Efficiency

실기 시연 수집에서 경험한 데이터 확보 비용과 행동 분포의 제한은 이후 World Model 프로젝트의 문제의식으로 이어졌습니다. 후속 프로젝트는 별도의 SO-100 데이터셋으로 수행했으며, 본 프로젝트의 SO-101 시연 데이터를 직접 재사용하지 않았습니다.
