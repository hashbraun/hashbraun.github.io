S · Situation

2026 INHA AI Challenge는 로봇의 첫 프레임과 joint-action 시퀀스가 주어졌을 때 미래 프레임을 예측하는 action-conditioned video generation world model을 요구했다.

기반 모델인 Cosmos-Predict3-Nano는 프리트레인 시 사용된 action distribution과 태스크의 액션 표현 사이에 방향성 불일치 문제가 있었고, LoRA 소자 튜닝만으로는 리더보드에서 유의한 개선을 얻기 어려웠다.

T · Task

  • Cosmos3-Nano에 SO-100 액션 토큰을 흘려 넣을 경로를 만든다.
  • 액션 표현 자체를 프리트레인 분포에 맞게 다시 디자인한다.
  • 리더보드에서 유의한 개선을 만드는 튜닝 절차를 확립한다.

A · Action

  • Action Injection Module — action_proj_in/out + action-modality embedding을 base LR로 직접 학습하여 SO-100 액션 토큰을 비디오 백본으로 라우팅 (action MAE −43.2%).
  • LoRA 파인튜닝 (rank 32) — attention (add_q/k/v_proj, to_add_out)과 MLP projection (gate/up/down_proj)에 LoRA 부착 (action MAE −8.6%).
  • Action 표현 재설계 — 절대 joint angle이 Cosmos3 프리트레인 분포와 호환되지 않는 방향성 mismatch를 진단, end-effector delta + gripper [0,1] 정규화로 교체 (action MAE −8.5%).
