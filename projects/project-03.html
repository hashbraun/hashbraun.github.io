챌린지 데이터 예시입니다. SO-100의 초기 프레임 6개(상단)와 이에 대응하는 15-step joint-angle 시퀀스(하단)를 보여줍니다. 모델은 각 초기 프레임과 액션 시퀀스를 조건으로 미래 15프레임을 생성합니다.

VLA 경험에서 출발한 데이터 효율성 문제

앞선 RILS Lab 프로젝트에서 SO-101 시연 데이터를 직접 수집하고 VLA 정책을 학습하면서, 실제 로봇 데이터를 확보하는 데 드는 시간과 다양한 상태·행동을 충분히 포함시키는 일이 중요하다는 점을 경험했습니다. 이 경험을 바탕으로 World Model을 활용해 action-conditioned rollout을 생성하고, 로봇 학습에 활용할 수 있는 데이터를 확장하는 방향에 관심을 갖게 되었습니다.

이번 프로젝트에서는 별도의 SO-100 데이터셋으로 생성 영상을 만들고, 생성 결과를 직접 재생·비교해 모델이 어떤 행동 조건에서 안정적이거나 실패하는지 분석했습니다. 영상이 생성된다는 사실만으로 학습 데이터로서 유용하다고 볼 수 없으므로, action MAE와 Good/Bad rollout을 함께 살펴 데이터 선별 및 모델 튜닝의 단서를 찾았습니다.

요약. SO-100의 초기 프레임과 joint-action 시퀀스를 조건으로 미래 영상을 생성하는 과제에서, 사전학습 모델과 태스크 액션 표현의 mismatch를 분석했습니다. Action Injection, LoRA, EE-Delta 재표현, checkpoint selection을 단계적으로 실험해 리더보드 성능을 개선했습니다. 생성 영상이 실제 정책 학습에 유효한지는 이 프로젝트에서 검증 범위에 포함되지 않았습니다.

01 · Problem & Data Analysis

2026 INHA AI Challenge(Dacon 236736)의 과제는 로봇의 초기 관측 프레임과 액션 시퀀스를 입력받아 이후 15개 프레임을 예측하는 것이었습니다. 따라서 일반적인 텍스트-비디오 생성과 달리, 생성된 영상이 초기 장면을 유지하면서 주어진 로봇 액션에 맞춰 변화해야 했습니다. 평가 점수는 0.3 × (1 − DINO cosine similarity) + 0.3 × (1 − VideoR3D cosine similarity) + 0.4 × Action MAE로 구성되며, 낮을수록 좋은 결과입니다.

평가 점수는 DINO 이미지 특징 유사도, VideoR3D 동영상 특징 유사도, Action MAE를 결합하며 낮을수록 좋습니다. 이 구조에서는 영상이 시각적으로 자연스러운지만으로는 충분하지 않고, 예측된 액션 값이 정답 액션과 얼마나 가까운지도 중요했습니다. 초기 분석에서 사전학습 모델의 액션 입력 분포와 대회 데이터의 절대 관절 각도 표현이 잘 맞지 않는 문제를 확인했습니다.

SO-100 데이터의 관절별 액션 값·변화량·속도와 그리퍼 및 어깨 관절의 궤적을 분석하고, 학습 데이터와 평가 데이터의 분포 차이를 비교했습니다. 이 결과를 바탕으로 액션 표현을 재설계하고 초기 프레임 정보를 보존하는 후처리를 검토했습니다.

02 · Baseline & Model Selection

기반 모델 후보를 고를 때는 생성 품질뿐 아니라 액션 조건을 모델 내부에 연결할 수 있는지, 학습 자원과 추론 시간이 과제 규모에 적합한지를 함께 고려했습니다. Cosmos-Predict3-Nano는 비교 대상인 DreamZero(Wan2.1-I2V-14B)보다 작은 8B급 백본을 사용하고, 액션과 영상 정보를 함께 다루는 구조여서 제한된 실험 자원 안에서 액션 조건부 예측을 검증하기에 적합하다고 판단했습니다.

학습 시간과 추론 경로 비교

동일한 A6000 Ada 환경에서 비교한 기록상 Cosmos3-Nano는 10k step 환산 학습 시간이 약 1.25시간이었고, DreamZero는 약 12시간이었습니다. DreamZero의 216개 샘플 추론은 33분 48초(샘플당 약 9.4초)가 소요됐습니다. Cosmos3-Nano는 latent 공간에서 액션과 영상 생성을 함께 처리하는 구조이며, DreamZero는 Wan2.1-I2V-14B 백본을 사용해 여러 chunk를 순차 생성하는 경로였습니다. 학습 자원과 액션 조건을 처리하는 모델 구조를 고려해 Cosmos3-Nano를 주 실험 모델로 선택했습니다. 이후에는 백본 교체보다 액션 입력 경로와 표현을 개선하는 데 집중했습니다.

03 · Action Conditioning

액션 정보가 모델 내부로 들어가는 경로 추가

기반 모델은 이미지와 텍스트 등 사전학습 모달리티를 처리할 수 있었지만, 이번 과제의 SO-100 6차원 액션 시퀀스를 동일한 방식으로 입력할 경로는 준비되어 있지 않았습니다. 따라서 액션 값을 단순히 프롬프트에 덧붙이는 대신, 액션 전용 투영층인 action_proj_in과 action_proj_out, 액션 모달리티 임베딩을 추가해 액션 특징이 영상 생성 과정에 전달되도록 구성했습니다.

새로 추가한 액션 입력 경로는 별도 학습률로 최적화하고, 기존 백본은 LoRA 중심으로 조정했습니다. 이 단계에서 Action MAE가 초기 설정 대비 43.2% 감소했습니다. 액션 조건과 생성 결과의 관계는 평가 샘플별 예측 액션과 정답 액션 사이의 MAE를 계산한 뒤, 216개 샘플을 오차 순으로 정렬해 상·하위 사례의 생성 프레임과 rollout을 비교하는 방식으로 살펴봤습니다. 낮은 오차 사례에서는 로봇 팔과 주변 물체의 상대적 배치가 비교적 안정적으로 유지됐고, 높은 오차 사례에서는 후반부 팔 형상이 흐려지거나 물체 위치가 어긋나는 경향이 관찰됐습니다. 따라서 확인된 결과는 액션 예측 정합도와 생성 영상의 시각적 안정성이 함께 변하는 샘플별 경향입니다. 이를 입력 액션의 물리적 궤적을 정확히 재현했다는 로봇 수준 검증과 동일하게 해석하지는 않았습니다.

04 · Action Representation

절대 관절 각도에서 End-Effector Delta로

첫 번째 시도에서는 데이터에 포함된 관절 각도(joint angle)를 그대로 액션 조건으로 사용했습니다. 그러나 이 표현은 로봇의 현재 자세에 따라 값의 범위와 변화 의미가 달라지고, 사전학습 모델이 기대하는 액션 분포와도 맞지 않았습니다. 실제로 절대 관절 각도를 사용한 40k 학습 결과는 리더보드 0.300으로, 학습하지 않은 초기 모델의 0.268보다 나빠졌습니다. 단순히 액션 입력 경로를 추가하는 것만으로는 표현 공간의 차이를 해결할 수 없다는 점을 확인했습니다.

이에 관절별 절대 위치 대신 로봇 말단장치(end-effector)의 상대 이동량인 EE-Delta로 액션을 다시 표현했습니다. 그리퍼 값도 0~1 범위로 정규화해 이동량과 개폐 상태가 서로 다른 스케일로 입력되도록 구성했습니다. 이 표현으로 학습한 EE-Delta 기반 실험 모델은 리더보드 0.2454를 기록했고, 절대 관절 각도 기반 결과보다 점수가 개선됐습니다. 별도 액션 평가에서도 Action MAE가 추가로 8.5% 감소했습니다.

이 결과는 모델 크기나 학습 횟수를 늘리는 것보다, 모델이 학습하기 쉬운 형태로 액션을 표현하는 것이 중요하다는 점을 보여줍니다.

05 · Temporal Anchoring

초기 관측 프레임 정보 보존

Temporal Anchoring은 생성 영상의 초기 장면이 입력 프레임과 크게 달라지는 현상을 줄이기 위한 픽셀 기반 후처리입니다. 각 생성 프레임과 입력 시퀀스의 첫 프레임을 같은 크기로 맞춘 뒤, 두 프레임의 픽셀 값을 1:1 비율로 가중 합성(50:50 blending)합니다. 이 과정은 모델의 가중치나 액션 예측 경로를 변경하지 않으며, 생성된 프레임에 초기 관측의 색상과 공간 배치 정보를 다시 혼합해 시각적 기준점을 유지하도록 합니다.

06 · Fine-tuning & Optimization

LoRA로 학습 범위와 자원 사용 조정

8B급 백본 전체를 업데이트하는 방식은 실험에 필요한 GPU 메모리와 학습 시간이 커질 수 있어, attention 및 MLP projection에 rank 32 LoRA를 적용했습니다. 구체적으로 add_q/k/v_proj, to_add_out, gate/up/down_proj에 LoRA를 연결해 사전학습 가중치를 대부분 유지하면서 액션-영상 정렬에 필요한 파라미터를 학습했습니다.

학습 설정만큼 추론 환경도 병목이었습니다. Blackwell 환경에서 기존 PyTorch 2.6 + CUDA 12.4 조합은 해당 GPU 아키텍처 커널을 지원하지 않아 별도 환경을 구성했습니다. RTX PRO 6000 Blackwell 95GB에 맞춰 PyTorch nightly CUDA 13.0 환경을 만들었고, diffusion step 처리 시간은 약 11초에서 1.5초로 줄어 약 7배 빨라졌습니다.

아래 비교표의 학습 시간과 DreamZero 추론 시간은 동일한 A6000 Ada 환경에서 확인한 기록입니다. Cosmos3-Nano의 216개 샘플 전체 추론 시간은 기록을 확인하지 못해 공란 대신 미측정으로 표시했습니다. Blackwell의 diffusion step 단축 결과는 별도 하드웨어 환경에서 측정한 최적화 결과입니다.

최종 제출 모델은 B4 학습의 step 6000 체크포인트입니다. 대회 평가 점수는 초기 Cosmos3-Nano의 0.268에서 최종 0.2407로 낮아졌습니다. 중간 실험에서 절대 관절 각도 기반 모델은 0.300으로 성능이 악화됐지만, EE-Delta와 정규화 Gripper 표현을 적용한 모델은 0.2454를 기록했습니다.

생성 영상은 216개 평가 샘플의 Action MAE를 기준으로 정렬하고, 오차가 낮은 상위 3개와 높은 하위 3개의 첫 프레임·중간 프레임·후반 프레임 및 rollout을 비교했습니다. 낮은 오차 그룹(MAE 0.33~0.37)은 로봇 팔의 형상과 배경 배치가 비교적 안정적이었습니다. 높은 오차 그룹(MAE 1.29~1.54)은 영상 후반부에서 팔 형상이 흐려지거나 물체 위치가 어긋났으며, 큰 Gripper 이동이나 배경 물체가 많은 장면에 집중됐습니다. 따라서 이번 분석에서 확인한 핵심은 평균 점수뿐 아니라 액션 변화가 크거나 장면이 복잡한 샘플에서 예측 오차와 시각적 불안정성이 함께 커진다는 점입니다.

08 · Retrospective — 액션 표현과 생성 결과의 정렬

이번 프로젝트에서 가장 큰 개선은 모델 규모를 키우는 것이 아니라, 사전학습 모델의 액션 입력 구조와 SO-100 데이터의 표현 차이를 찾아 조정한 데서 나왔습니다. Action Injection으로 액션 특징이 영상 생성 경로에 들어가도록 연결했지만, 절대 관절 각도를 그대로 사용한 실험은 초기 모델보다 점수가 나빠졌습니다. 이후 EE-Delta와 Gripper 정규화를 적용하자 점수가 0.2454로 개선됐고, 최종 B4 step 6000 체크포인트는 0.2407을 기록했습니다.

216개 rollout을 Action MAE 순으로 정렬해 비교한 결과, 큰 Gripper 이동이나 배경 물체가 많은 장면에서 액션 예측 오차가 높아지고 후반부 영상의 안정성이 낮아지는 경향을 확인했습니다. 따라서 평균 점수만으로 모델을 판단하기보다 액션 오차와 생성 영상을 함께 분석해 취약한 입력 조건을 찾는 과정이 중요했습니다.

이 프로젝트의 성과는 로봇 제어 정책을 완성하거나 생성 영상을 실제 정책 학습에 검증한 것이 아니라, 사전학습 비디오 생성 모델을 로봇 액션 조건에 맞게 적응시키고 평가 데이터의 실패 양상을 분석한 데 있습니다. 앞선 SO-101 VLA 시연 수집 경험에서 출발한 데이터 효율성 문제를, 별도의 SO-100 데이터셋을 이용한 action-conditioned 미래 영상 예측과 모델 적응 실험으로 확장했습니다.
