PROJECT 07

AGI을 활용한 영상 데이터 오토라벨링 프로그램 개발

산학협력 · with 한국로봇융합연구원 (KIRO) · 산길·예초(Mowed / Unmowed) 이미지 · SAM (vit_h) + GPT-4o-mini + DBSCAN Mask Merge
SAM (vit_h) SamAutomaticMaskGenerator GPT-4o-mini (OpenRouter) Dynamic Class Extraction IoU Dedup DBSCAN Mask Merging Morphological Closing
Role 참여연구원 (인하대 학사과정)
Period Apr. 2025 – Sep. 2025
Partner KIRO · 인하대학교 (책임: 안우진 교수)
Domain CV · Zero-Training Auto-Labeling

* 산길 원본 vs 오토라벨링 결과 (좌: zed_7_images_00300.png, 우: 6개 클래스 · 28개 마스크). Person / Vehicle / Sky / Mowed Area / Unmowed Area / Tree.

S · Situation

KIRO(한국로봇융합연구원) 산학협력 과제로, 산업 현장의 대규모 이미지 데이터를 사람 개입을 최소화한 오토 라벨링 파이프라인으로 처리해 인건비·시간을 절감하는 것이 과제 목표였다. 인하대 팀이 AGI + LLM 연계 알고리즘을, KIRO가 현장 데이터 수집·검증을 맡는 구성.

첫 적용 도메인은 자율 예초 로봇이 다루는 산길·초지 이미지로, 특히 예초 완료 영역(Mowed) / 미예초 영역(Unmowed) 구분이 요구되었다. 그러나 이 클래스 체계로 사전 라벨된 공개 데이터셋이 없고, 산길은 풀·초지 경계가 연속적이라 수동 폴리곤 라벨링의 라벨러 편차와 시간 비용이 매우 컸다. 학습 없이 곧바로 라벨 후보를 뽑아낼 수 있는 제로-트레이닝 파이프라인이 필요했다.

T · Task

  • 학습 없이도 산길 이미지에 등장하는 클래스 목록을 이미지별로 자동 추출한다 (사전 정의된 라벨 세트에 종속되지 않도록).
  • SAM으로 마스크 후보를 조밀히 생성하고, 각 마스크에 추출된 클래스 중 하나를 부여해 라벨을 완성한다.
  • SAM이 뱉는 과분할된 인접 마스크를 같은 클래스끼리 병합해, 예초 여부 판단에 실제로 쓸 수 있는 깔끔한 영역 단위 라벨로 정리한다.

A · Action

  • Stage 1 · 동적 클래스 추출 (GPT-4o-mini) — 각 산길 이미지를 base64로 인코딩해 GPT-4o-mini (OpenRouter)에 전달, "길/사람·동물/차량/예초·비예초/배경(Sky·Rock·Tree·Building)/Other" 6개 카테고리 힌트를 주고 해당 이미지에 실제로 등장하는 클래스 목록만 추출. 예: [Road, Mowed Area, Unmowed Area, Sky, Tree, Others].
  • Stage 2 · Dual-config SAM 마스크 생성 — SAM vit_h + SamAutomaticMaskGenerator를 두 설정으로 실행: (a) 세밀 points_per_side=32, pred_iou=0.85, stability=0.92, min_area=300, (b) 큰영역 points_per_side=16, pred_iou=0.7, stability=0.85, min_area=2000. 두 결과를 합친 뒤 IoU ≥ 0.7 기준 중복 제거 (큰 마스크 우선).
  • Stage 3 · 마스크별 클래스 분류 (GPT-4o-mini) — 각 마스크의 bbox로 원본을 crop해 다시 GPT-4o-mini에 넘기고, Stage 1에서 뽑힌 클래스 목록으로만 답하도록 제약 ("반드시 위 목록에서만 선택", 없으면 'Other'). 마스크 하나당 1회 호출로 라벨 부여.
  • Stage 4 · DBSCAN 마스크 병합 + 형태학적 정리 — 같은 클래스의 마스크들의 중심점(mask centroid)을 이미지 크기로 정규화해 DBSCAN (eps=0.1, min_samples=1)으로 인접 마스크를 클러스터링, 클러스터 내 마스크는 OR 병합 후 MORPH_CLOSE (10×10 ellipse)로 작은 구멍 제거. 예초 영역이 여러 조각으로 쪼개져도 하나의 영역으로 통합.

R · Result

학습 없이도 산길 이미지에서 예초 완료 영역(Mowed) / 미예초 영역(Unmowed)을 포함한 6개 안팎의 클래스에 대해 픽셀 단위 오토라벨을 생성하는 파이프라인을 완성하였다. 동적 클래스 추출 → SAM dual-config → per-mask LLM 분류 → DBSCAN 병합으로 이어지는 4단계 구조 덕에, 라벨 스키마를 새로 정의하지 않고도 이미지 특성에 맞춰 6~15개 마스크 규모의 세그멘테이션 결과를 곧바로 얻을 수 있었다.

* 정성 결과 — 좌: 4클래스 · 30 마스크 (하늘/나무 + 예초/비예초), 우: 6클래스 · 34 마스크 (예초·비예초 능선이 넓게 유지됨).

  • 실행 환경 — Google Colab (GPU) · Python · PyTorch · segment-anything · scikit-learn · OpenCV
  • Segmenter — Meta SAM (vit_h, sam_vit_h_4b8939.pth) · SamAutomaticMaskGenerator dual-config
  • LLM — openai/gpt-4o-mini via OpenRouter (base64 vision · Stage 1 클래스 추출 + Stage 3 마스크 분류)
  • Post-processing — IoU 0.7 dedup · DBSCAN (eps=0.1, min_samples=1) · MORPH_CLOSE 10×10
  • Data — KIRO가 수집한 산길 · 예초 현장 이미지, ZED 스테레오 카메라 (forest_image/zed_*.png)
  • Team — 안우진 (인하대 조교수, 책임) · 장선호 (KIRO 주임, 공동연구자) · 조윤재 · 권유진 · 김건우 (인하대 학사 · 참여연구원)
