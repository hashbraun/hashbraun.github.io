PROJECT 07

Zero-Shot Image Auto-Labeling with VLM and SAM

산학협력 · with 한국로봇융합연구원 (KIRO) · 산길·예초(Mowed / Unmowed) 이미지 · SAM (vit_h) + GPT-4o-mini + DBSCAN Mask Merge

산길 원본 이미지와 자동 라벨링 결과입니다. zed_7_images_00300.png에서 Person, Vehicle, Sky, Mowed Area, Unmowed Area, Tree의 6개 클래스를 추출하고 28개 마스크를 생성했습니다. 마스크 수는 해당 이미지의 출력 결과이며 라벨 정확도를 나타내는 지표는 아닙니다.

GPT-4o-mini에 이미지 전체를 입력해 장면에 등장하는 클래스 후보를 추출하고, SAM으로 마스크를 생성한 뒤 마스크별 클래스를 분류·병합하는 zero-shot 자동 라벨링 도구를 구현했습니다. 별도 도메인 모델 학습 없이 범용 VLM의 장면 이해와 SAM의 영역 제안을 결합했습니다.

01 · Problem Definition

KIRO(한국로봇융합연구원) 산학협력 과제로, 산업 현장의 대규모 이미지 데이터를 사람의 개입을 최소화한 자동 라벨링 파이프라인으로 처리해 인건비와 작업 시간을 줄이는 것이 과제 목표였습니다. 인하대 팀은 AGI·LLM 연계 알고리즘을 개발하고, KIRO는 현장 데이터 수집과 검증을 담당했습니다.

첫 적용 도메인은 자율 예초 로봇이 사용하는 산길·초지 이미지였습니다. 특히 예초 완료 영역(Mowed)과 미예초 영역(Unmowed)을 구분해야 했지만, 해당 클래스 체계로 사전 라벨링된 공개 데이터셋이 없었습니다. 풀과 초지의 경계도 연속적으로 이어져 수동 폴리곤 라벨링에 시간이 많이 들고 작업자별 편차가 발생했습니다. 이에 모델을 별도로 학습하지 않고도 라벨 후보를 생성할 수 있는 제로 트레이닝 파이프라인을 설계했습니다.

02 · Scope & Design Goals

  • 이미지 전체의 장면 문맥을 VLM에 전달해 실제 등장하는 클래스 후보를 추출함.
  • SAM AutomaticMaskGenerator의 서로 다른 설정으로 작은 객체와 넓은 영역의 마스크 후보를 함께 생성함.
  • 마스크별 클래스 분류 결과에서 중복·인접 영역을 정리해 활용 가능한 라벨 후보를 생성함.
  • 별도 도메인 데이터 학습 없이 범용 VLM과 SAM을 조합한 zero-shot 파이프라인을 구성함.

03 · Design & Implementation

고정 라벨 학습 대신 이미지별 클래스 추출

적용 도메인에는 Mowed·Unmowed를 포함한 현장 클래스 체계로 사전 라벨링된 학습 데이터가 충분하지 않았습니다. 산길·초지처럼 일반 화각의 장면에서는 객체와 배경의 전체 맥락을 함께 볼 수 있어, GPT-4o-mini에 이미지 전체를 전달해 등장 클래스를 추출하는 방식이 유효했습니다. 도메인 전용 segmentation 모델을 파인튜닝하는 대신 VLM은 클래스 후보를, SAM은 픽셀 영역 생성을 담당하도록 역할을 분리했습니다.

작은 객체와 넓은 지면 영역을 함께 포착

SAM AutomaticMaskGenerator를 세밀한 설정과 큰 영역을 우선하는 설정으로 각각 실행했습니다. 두 결과를 합친 뒤 IoU 0.7 이상 중복 마스크를 제거해 작은 객체 경계와 넓게 이어지는 초지 영역을 함께 확보하려 했습니다. 이후 마스크 crop의 클래스를 앞 단계에서 추출한 후보 목록으로 제한하고, 동일 클래스의 인접 마스크를 DBSCAN과 형태학적 닫힘으로 정리했습니다.

이미지별 클래스 후보 추출

먼저 이미지 전체를 base64로 인코딩해 GPT-4o-mini에 전달하고, 해당 장면에 실제로 등장하는 클래스 목록을 추출했습니다. 일반 화각의 장면에서는 전체 이미지의 공간적·의미적 맥락을 함께 제공하는 편이 객체와 배경을 구분하는 데 유리했습니다. 사전에 고정된 라벨 목록만 강제하면 이미지에 없는 클래스까지 포함될 수 있으므로, 도로·사람·차량·예초/비예초 영역·배경 등 과제 목적을 안내하되 실제 등장한 클래스만 반환하도록 구성했습니다.

서로 다른 크기의 마스크 생성

SAM vit_h의 자동 마스크 생성기를 세밀한 설정과 큰 영역을 우선하는 설정으로 각각 실행했습니다. 두 결과를 합친 뒤 IoU 0.7 이상으로 겹치는 중복 마스크를 제거했습니다. 세밀한 설정은 작은 객체와 경계를 포착하고, 큰 영역 설정은 초지처럼 넓게 이어지는 영역을 놓치지 않도록 하기 위한 선택이었습니다.

마스크별 클래스 분류와 영역 병합

마스크별 분류 단계에서는 각 마스크의 바운딩 박스 영역을 crop해 GPT-4o-mini에 전달하고, 앞 단계에서 추출한 클래스 중 하나만 선택하도록 제한했습니다. 즉, 전체 이미지 입력은 장면의 클래스 후보를 찾는 데 사용하고, crop 입력은 개별 영역의 세부 클래스를 판별하는 데 사용했습니다. 이후 같은 클래스에 속한 마스크 중심점을 기준으로 DBSCAN 군집화를 수행하고, 군집 안의 마스크를 합친 뒤 10×10 타원형 커널의 형태학적 닫힘 연산으로 작은 구멍을 정리했습니다.

04 · Experiments & Results

GPT-4o-mini의 이미지 전체 입력으로 장면별 클래스 후보를 추출하고, SAM 마스크 생성·마스크별 클래스 분류·DBSCAN 병합을 연결해 별도 도메인 모델 학습 없이 라벨 후보를 생성했습니다. 일반 화각의 산길 이미지에서 Mowed Area와 Unmowed Area를 포함한 여러 클래스가 분리되는 정성 결과를 확인했습니다. 다만 이 결과는 선택한 이미지의 출력 사례를 확인한 것으로, 정답 마스크와 비교한 정량 성능이나 데이터셋 전체에 대한 일반화 성능을 검증한 것은 아닙니다.

첫 번째 정성 평가 장면에서는 Sky, Mowed Area, Unmowed Area, Tree의 4개 클래스를 기준으로 30개 마스크를 생성했습니다. 예초·비예초 영역이 함께 나타나는 장면에서 두 영역의 후보 마스크가 분리되는지 확인했습니다.

넓은 초지와 능선이 포함된 두 번째 결과입니다. 6개 클래스에 대해 34개 마스크를 생성했으며, DBSCAN 병합 이후에도 예초·비예초 영역의 큰 경계가 유지되는지 확인할 수 있습니다.

두 장면의 결과는 서로 다른 배경·초지 형태에서도 예초·비예초 후보 영역을 생성할 수 있음을 보여주는 정성 사례입니다. 마스크 개수와 클래스 분리는 출력 사례의 관찰값이며, 정답 마스크와 비교한 IoU나 클래스별 정밀도·재현율을 의미하지 않습니다.

  • 실행 환경 — Google Colab (GPU) · Python · PyTorch · segment-anything · scikit-learn · OpenCV
  • Segmenter — Meta SAM (vit_h, sam_vit_h_4b8939.pth) · SamAutomaticMaskGenerator dual-config
  • LLM — openai/gpt-4o-mini via OpenRouter (base64 vision · Stage 1 클래스 추출 + Stage 3 마스크 분류)
  • Post-processing — IoU 0.7 dedup · DBSCAN (eps=0.1, min_samples=1) · MORPH_CLOSE 10×10
  • Data — KIRO가 수집한 산길 · 예초 현장 이미지, ZED 스테레오 카메라 (forest_image/zed_*.png)
  • Team — 안우진 (인하대 조교수, 책임) · 장선호 (KIRO 주임, 공동연구자) · 조윤재 · 권유진 · 김건우 (인하대 학사 · 참여연구원)
  • Notes — 학습 없는 파이프라인이라 Stage 3 LLM 분류 편차와 DBSCAN eps 튜닝이 다음 반복의 개선 포인트

05 · Technical Issues & Improvements

주요 한계는 GPT-4o-mini의 마스크별 클래스 선택 편차와 DBSCAN의 거리 임계값에 결과가 민감할 수 있다는 점입니다. 특히 경계가 모호한 Mowed·Unmowed 영역은 crop 범위와 장면 맥락에 따라 분류가 달라질 수 있습니다. 다음 단계에서는 사람 검수 라벨을 기준으로 클래스별 오류와 경계 품질을 측정하고, DBSCAN eps 및 SAM 생성 설정을 검증 세트에서 조정해야 합니다.

후속 연구 방향 · Geometry-aware Robust Labeling

단일 이미지의 색상과 장면 문맥에 의존하는 분류를 보완하기 위해, 카메라 기하 정보에서 얻는 깊이·3D 구조와 RGB 기반 의미 정보를 분리하는 방법을 탐구하고 있습니다. 스테레오 원본과 카메라 보정 정보가 남아 있다면 disparity로 metric depth를 계산하고, 여러 시점에서 생성한 마스크를 3D 공간에 정합해 라벨을 통합하는 방안을 먼저 검토할 예정입니다. 단일 RGB 이미지밖에 없다면 VGGT (CVPR 2025)를 이용해 상대 깊이와 point map을 추정하는 방법도 확인하고 있습니다. 다만 실제 크기까지 비교하려면 카메라 정보나 기준 물체처럼 scale을 정할 기준이 필요합니다.

조명 변화·그림자·블러가 있는 이미지는 먼저 품질을 확인하고, 분류 결과가 불확실한 경우에만 보정이나 여러 시점의 재추론을 적용하는 흐름을 검토하고 있습니다. SAM2Object (CVPR 2025)와 MV3DIS (CVPR 2026)의 다중 시점 마스크 일관성 접근도 함께 살펴보고 있습니다. RobustSAM (CVPR 2024)은 저품질 이미지에서 SAM의 성능 저하를 줄이기 위해 추가 학습을 사용하는 연구이므로, 현재 파이프라인을 바로 대체하기보다 후속 비교 대상으로 검토할 예정입니다. 우선 스테레오 정보의 활용 가능성과 단일 이미지 깊이 추정의 차이를 확인하고, 계산 비용과 라벨 일관성을 함께 비교해 보겠습니다.
