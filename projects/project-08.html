PROJECT 08

CV AI Agent: Video Action Recognition with VLMs

Zero training · Qwen3-VL structured-output pipeline · 15 action categories
Qwen3-VL Structured Output Constraint-aware Prompt Adaptive ffmpeg SLURM Batch
Role AI Researcher
Period Jul. 2025 – Apr. 2026
Domain VLM · Video Understanding · Prompt Eng.

S · Situation

15개 카테고리에 대한 초 단위 정밀 타임스탬프 액션 세그먼트가 필요했지만, 전용 action recognizer를 새로 학습할 자원과 시간이 없었다.

또한 원본 클립이 길어 그대로 VLM에 넣으면 OOM이 자주 발생, 전체 데이터셋 배치가 불가능했다.

T · Task

  • 학습 없이도 신뢰 가능한 액션 세그먼트를 뽑는 VLM 파이프라인을 설계한다.
  • SLURM 위에서 전체 데이터셋을 안전하게 배치 처리할 수 있게 한다.

A · Action

  • Qwen3-VL structured output 파이프라인 — 액션 정의, 우선순위 규칙, 가시성 조건, 시간 임계값(≥5s)을 강제하는 constraint-aware 프롬프트 엔지니어링 프레임워크를 설계해 라벨 신뢰도를 높이고 hallucination을 완화.
  • Adaptive ffmpeg downsampling (pre-VLM) — 장시간 클립에서 OOM을 방지, SLURM 위에서 전 데이터셋 배치를 가능하게 함.

R · Result

전용 액션 인식기를 학습하지 않고도, Qwen3-VL + constraint-aware structured output + adaptive ffmpeg의 조합만으로 원본 MP4를 초 단위 타임스탬프 액션 세그먼트로 변환하는 파이프라인을 확보하였고, SLURM 위에서 전 데이터셋 배치 처리가 가능한 상태로 안착시켰다.

* 9개 샘플 프레임에 Qwen3-VL이 출력한 MM:SS 타임스탬프 · 액션 라벨을 오버레이. Bp_free17 / Hyeyoung_Lee / room01 세션.
