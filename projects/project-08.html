PROJECT 08

CV AI Agent: Video Action Recognition with VLMs

Zero training · Qwen3-VL structured-output pipeline · 15 action categories
Qwen3-VL Structured Output Constraint-aware Prompt Adaptive ffmpeg SLURM Batch
Role AI Researcher
Period Mar. 01, 2026 – Aug. 31, 2026
Domain VLM · Video Understanding · Prompt Eng.
이 페이지에서
Problem DefinitionSolution GoalsImplementationResults

원본 MP4를 FFmpeg로 샘플링한 뒤 Qwen3-VL에 입력하고, 행동별 시작·종료 시점을 구조화된 액션 세그먼트로 저장하는 전체 흐름입니다.

01 · Problem Definition

15개 행동 카테고리에 대해 시작·종료 시점을 초 단위로 표시한 액션 세그먼트가 필요했습니다. 그러나 전용 행동 인식 모델을 새로 학습할 데이터와 시간이 충분하지 않아, 사전학습된 비전-언어 모델(VLM)을 활용하는 접근을 검토했습니다.

원본 영상은 길이가 길어 모든 프레임을 그대로 입력하면 GPU 메모리 부족(OOM)이 발생했습니다. 따라서 모델 선택뿐 아니라 영상 길이와 프레임 수를 조절해 전체 데이터셋을 안정적으로 처리하는 전처리 과정도 필요했습니다.

02 · Solution Goals

별도의 행동 인식 모델을 학습하지 않고도 Qwen3-VL을 이용해 영상의 행동 구간과 타임스탬프를 추출하고, 출력 형식을 검증해 일관된 JSON 결과로 저장하는 파이프라인을 구축하는 것을 목표로 삼았습니다. 또한 FFmpeg 전처리와 SLURM 배치 실행을 연결해 긴 영상이 포함된 전체 데이터셋을 처리할 수 있도록 했습니다.

03 · Implementation

행동 정의와 시간 조건을 포함한 구조화 출력

Qwen3-VL이 임의의 문장으로 행동을 설명하지 않고 정해진 15개 카테고리와 시간 구간을 반환하도록 프롬프트를 구성했습니다. 행동별 정의와 우선순위, 화면에서 확인할 수 있어야 하는 가시성 조건을 명시하고, 최소 지속 시간은 5초 이상으로 제한했습니다. 모델 출력은 JSON 구조로 받도록 해 후속 검증과 데이터 저장 과정에서 일관되게 처리할 수 있도록 했습니다.

영상 길이에 따른 적응형 프레임 샘플링

긴 영상을 그대로 모델에 전달하면 프레임 수가 많아져 메모리 부족이 발생할 수 있었습니다. 이를 줄이기 위해 FFmpeg로 영상 길이에 따라 프레임 샘플링 간격을 조정하고, 입력 해상도를 512픽셀 너비로 제한했습니다. 짧은 구간은 상대적으로 높은 프레임 빈도를 유지하고 긴 구간은 더 낮은 빈도로 샘플링해, 시간 흐름을 파악하는 데 필요한 정보를 남기면서 입력량을 통제했습니다.

시스템 상세 구조입니다. 전처리된 프레임을 Qwen3-VL이 JSON으로 변환하면 validator가 시간 구간과 스키마를 검사하고, 오류가 있는 출력은 수정 경로로 전달합니다. 전체 작업은 SLURM 배치로 실행합니다.

원본 영상에서 프레임을 추출하고 해상도와 샘플링 간격을 조정하는 전처리 예시입니다. 긴 영상의 입력량을 줄여 GPU 메모리 사용량을 통제합니다.

Qwen3-VL이 행동 카테고리와 시작·종료 시점을 JSON으로 채우는 과정입니다. 정해진 스키마로 결과를 받기 때문에 타임라인 생성과 후속 데이터 처리가 쉬워집니다.

04 · Results

전용 행동 인식 모델을 새로 학습하지 않고도 Qwen3-VL, 구조화 출력, 적응형 FFmpeg 전처리를 결합해 원본 MP4를 초 단위 액션 세그먼트로 변환하는 파이프라인을 구축했습니다. 또한 SLURM 배치 실행을 연결해 전체 데이터셋을 처리할 수 있는 작업 흐름을 마련했습니다.

원본 영상과 모델이 생성한 행동 타임라인을 비교한 예시입니다. 하나의 클립을 여러 행동 구간으로 나누고, 각 구간의 시작·종료 시점과 행동 카테고리를 시간축에 표시했습니다.

* Bp_free17 / Hyeyoung_Lee / room01 세션의 9개 샘플 프레임입니다. Qwen3-VL이 추출한 시작·종료 시각(MM:SS)과 액션 라벨을 각 프레임에 표시했습니다.
