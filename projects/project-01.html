PROJECT 01

Automated Labeling System for Smart-Elevator CCTV

with Hyundai Elevator · Top-down CCTV domain
YOLO11m-seg SAM2 Polygon-Mask Prompting Active Learning FastAPI React/Vite Docker SLURM NAS
Role AI Researcher
Period Jul. 2025 – Apr. 2026
Domain CV · Segmentation · Labeling Ops

S · Situation

스마트 엘리베이터 프로젝트에서 요구되는 학습 데이터는 탑뷰(top-down) 시점의 4K CCTV 영상이었다. 이 도메인은 COCO 계열 pretrained detector가 가정하는 시점(정면·측면)과 완전히 달라 기성 모델의 검출 성능이 심각하게 떨어지고, 그에 따라 수작업 라벨링 비용이 폭발적으로 증가하는 구조적 병목이 있었다.

SAM2 기반의 마스크 전파(video propagation)를 사용하더라도, centroid-point prompting은 마스크 초기 상태가 부정확할 때 클립 전체에 걸쳐 드리프트가 누적되는 불안정성을 보였다.

T · Task

  • 탑뷰 도메인에 특화된 세그멘테이션 검출기를 확보한다.
  • SAM2의 마스크 전파 파이프라인을 안정화하여 클립 전체의 트래킹 품질을 끌어올린다.
  • 모델 결과를 사람이 실제로 다중 사용자 환경에서 검수·수정할 수 있는 웹 라벨링 툴로 배포한다.
  • 초기 라벨 소량으로 시작해 모델이 데이터를 스스로 확장하는 사이클을 갖춘다.

A · Action

  • YOLO11m-seg 파인튜닝 — 4K 탑뷰 엘리베이터 영상 19K 프레임 · 241 시퀀스에 대해 탑뷰 도메인 적응.
  • Polygon-Mask Prompting — SAM2의 centroid-point prompting을 폴리곤 마스크 프롬프트로 교체해, 검증된 초기 마스크가 propagation의 앵커 역할을 하도록 재설계.
  • Active Learning 루프 — 저신뢰 프레임을 자동 큐잉하고 4× 오버샘플링 + replay로 지속 재학습.
  • 풀스택 배포 — FastAPI + React/Vite + Docker + SLURM + NAS mount 기반 다중 사용자 웹 툴로 사내 배포.
