PROJECT 01

Automated Labeling System for Smart-Elevator CCTV

with Hyundai Elevator · Top-down CCTV domain
YOLO11m-seg SAM2 Polygon-Mask Prompting Active Learning FastAPI React/Vite Docker SLURM NAS
Role AI Researcher
Period Mar. 2026 – May 2026
Domain CV · Segmentation · Labeling Ops

전체 시스템 흐름입니다. CCTV 프레임에서 객체 후보와 마스크를 생성하고, SAM2로 영상 구간에 전파한 뒤, 검수가 필요한 결과를 웹 도구로 전달해 수정 데이터가 다음 학습에 반영되도록 구성했습니다.

이 페이지에서
문제 정의해결 목표핵심 구현결과와 적용
프로젝트 개요. 탑뷰 4K 엘리베이터 CCTV에서 발생한 도메인 차이와 SAM2 마스크 전파 오류를 해결하기 위해, 검출 모델·마스크 프롬프팅·Active Learning·웹 라벨링 도구를 연결한 데이터 구축 파이프라인을 개발했습니다.

01 · Problem Definition — 탑뷰 도메인과 라벨링 병목

스마트 엘리베이터 프로젝트에서 요구되는 학습 데이터는 탑뷰(top-down) 시점의 4K CCTV 영상이었다. 이 도메인은 COCO 계열 pretrained detector가 가정하는 시점(정면·측면)과 완전히 달라 기성 모델의 검출 성능이 심각하게 떨어지고, 그에 따라 수작업 라벨링 비용이 폭발적으로 증가하는 구조적 병목이 있었다.

SAM2 기반의 마스크 전파(video propagation)를 사용하더라도, centroid-point prompting은 마스크 초기 상태가 부정확할 때 클립 전체에 걸쳐 드리프트가 누적되는 불안정성을 보였다.

02 · 해결 목표

  • 탑뷰 도메인에 특화된 세그멘테이션 검출기를 확보한다.
  • SAM2의 마스크 전파 파이프라인을 안정화하여 클립 전체의 트래킹 품질을 끌어올린다.
  • 모델 결과를 사람이 실제로 다중 사용자 환경에서 검수·수정할 수 있는 웹 라벨링 툴로 배포한다.
  • 초기 라벨 소량으로 시작해 모델이 데이터를 스스로 확장하는 사이클을 갖춘다.

03 · 핵심 구현 — 검출, 마스크 전파, 반복 라벨링

  • YOLO11m-seg 파인튜닝 — 4K 탑뷰 엘리베이터 영상 19K 프레임 · 241 시퀀스에 대해 탑뷰 도메인 적응.
  • Polygon-Mask Prompting — SAM2의 centroid-point prompting을 폴리곤 마스크 프롬프트로 교체해, 검증된 초기 마스크가 propagation의 앵커 역할을 하도록 재설계.
  • Active Learning 루프 — 저신뢰 프레임을 자동 큐잉하고 4× 오버샘플링 + replay로 지속 재학습.
  • 풀스택 배포 — FastAPI + React/Vite + Docker + SLURM + NAS mount 기반 다중 사용자 웹 툴로 사내 배포.

세부 처리 구조입니다. YOLO11m-seg가 객체 영역을 찾으면 폴리곤 마스크를 SAM2 입력으로 전달합니다. SAM2는 이를 기준으로 후속 프레임의 마스크를 추적하고, 신뢰도가 낮거나 수정이 필요한 프레임은 검수 후보로 모읍니다.

기존 중심점 프롬프트 방식입니다. 초기 마스크가 부정확하면 중심점 하나만으로 객체의 형태와 경계를 충분히 전달하지 못해, 프레임이 진행될수록 마스크가 주변 영역으로 벗어나는 현상이 나타납니다.

개선한 폴리곤 마스크 프롬프트 방식입니다. 점 하나가 아니라 객체의 영역과 경계를 함께 전달해, 초기 마스크를 기준으로 후속 프레임에서도 형태가 더 안정적으로 유지되도록 했습니다.

웹 라벨링 도구 사용 화면입니다. 자동 생성된 마스크를 검수하고 필요한 부분만 수정할 수 있도록 구성해, 프레임마다 반복하던 수동 입력을 줄였습니다.

3개 테스트 클립(각 60프레임)에서 두 프롬프트 방식의 Tracking IoU를 비교한 결과입니다. 폴리곤 마스크 프롬프트가 평균 55.4%p 높아, 마스크 전파의 안정성이 개선됐음을 보여줍니다.

최종적으로 사내 다중 사용자 웹 라벨링 툴로 배포되어, 탑뷰 CCTV 도메인에 대한 학습 데이터 확보 파이프라인의 인력 병목을 실질적으로 완화하였다.

결과. 폴리곤 마스크 프롬프트를 적용해 3개 테스트 클립 평균 Tracking IoU를 55.4%p 개선했습니다. 웹 라벨링 도구에서는 프레임당 클릭 수를 7회에서 2회로 줄였고, 60프레임 클립의 라벨링 시간은 30분에서 4분으로 단축했습니다. 이를 바탕으로 탑뷰 CCTV 데이터의 검수와 재학습을 반복할 수 있는 다중 사용자 웹 라벨링 시스템을 사내에 배포했습니다.
